# WS Manual Board

ヴァイスシュヴァルツ手動対戦盤面の試作版。

## Ver.0.1
- 公式プレイマットを参考にしたスマートフォン縦画面向けゾーン
- 2プレイヤー各50枚の仮カード（a〜n、14種類）
- シャッフル、ドロー、ゾーン間のカード移動
- ストックの上から指定枚数を控え室へ移動（内容非公開）
- リフレッシュ・リフレッシュダメージ・レベルアップの個別操作（試作）

## 注意
現時点では**単一ブラウザ内の試作**です。ルームコード、オンライン同期、非公開情報の安全な通信制御は未実装です。画面上の操作側切替は実際の対戦時のアクセス制御には使えません。特殊効果やルールの例外処理も未実装です。
